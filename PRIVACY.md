# Privacy Policy — Godot Strategy Game Studio

Publisher: TK Game Studio

This plugin contains only instruction files (skills) and reference notes for Claude. It does not include MCP servers, hooks, scripts, or any code that runs on your machine, and it does not connect to any service.

- The plugin itself collects, stores, or transmits no personal data.
- The plugin sends no data to TK Game Studio or any third party.
- Any work Claude does while using these skills (for example editing your Godot project) happens through the Claude product and tools you already use, under Anthropic's own privacy terms.

Questions: open an issue at https://github.com/TK-Game-Studio/godot-strategy-game-studio/issues
